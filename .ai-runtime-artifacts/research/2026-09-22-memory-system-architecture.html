图 1全系统总览

上行为写入链路（会话空闲后异步触发），中间是三个存储实体，下行为读取链路（每轮提问同步触发）。两条链路在存储层交汇，彼此不直接调用。

图 2读取链路：四路召回与融合

读链路是整套系统里分支最多的一段：一次提问先过预筛门，再经 LLM 拆解，然后四路并行召回，汇入同一个候选池去重后统一重排。

看图时最容易误判的一处：写入与读取并不是两条互相驱动的链路。写入端只在「空闲」这一个条件下放行，读取端每轮都跑；两者之间没有回写反馈，唯一的信息回流是引用评分——注入进 prompt 的 memory_id 会被记下，等下一次 idle 抽取时用于给这些记忆加访问计数。
