### bge-v1.5 的两条官方实现约束（实测自模型卡）

1. **v1.5 不需要指令前缀**。模型卡原文：「release `bge-*-v1.5` embedding model to alleviate the issue of the similarity distribution, and **enhance its retrieval ability without instruction**」。v1.0 的 `为这个句子生成表示以用于检索相关文章：` 前缀在 1.5 上**不必加**。
2. **必须 `normalize_embeddings=True`**。官方示例：
   ```python
   model = SentenceTransformer('BAAI/bge-base-zh-v1.5')
   embeddings_1 = model.encode(sentences_1, normalize_embeddings=True)
   ```
   归一化后才与 collection 的 `hnsw:space = "cosine"` 语义一致。

> openakita 把 `sentence-transformers + chromadb + regex` 声明为 **≈2500 MB** 可选模块（`optional_modules.json:4-18`）——那是含 PyPI 全量 CUDA wheel 的口径。本项目按 **CPU-only** 约束后约 600 MB。

## 六、结论

1. 三个新依赖与 `requires-python >= 3.11` 兼容，**以 `vector` extra 形式引入**，不进入核心 `dependencies`。
2. 默认模型定 **`BAAI/bge-small-zh-v1.5`**（512 维 / max_seq 512 / 95.8 MB），中文可用且体积可控。
3. 维度必须**显式配置**：512（bge-small-zh）与 768（bge-base-zh / text2vec）与 384（MiniLM 系）互不兼容，换模型必须重建索引——这正是 openakita 漏配 `embedding_dimensions` 导致缺陷的根因（调研文档 §5「三个已知缺陷」第 1 条）。
4. 本机 Python **3.13** 与 CI 基线 **3.11** 存在落差，验证须双跑。
