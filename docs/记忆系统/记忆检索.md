```python
def retrieve(self, query, recent_messages, active_persona, max_tokens=700, precomputed_keywords=None):
    # Step 1: 查询预处理（Gate 守卫）
    prepared = MemoryQueryPreprocessor.prepare(query, recent_messages)
    if prepared.skip:
        return ""  # ← 大量查询在此被短路

    # Step 2: 关键词拆解
    if precomputed_keywords:
        # IntentAnalyzer 已给出关键词，跳过 LLM 拆解
        search_keywords = precomputed_keywords
    else:
        decomposed = self._decompose_query(query, recent_messages)
        search_keywords = decomposed["keywords"]  # LLM 或规则拆解

    # Step 3: 构建增强查询
    enhanced_query = self._build_enhanced_query(query, recent_messages, search_keywords)

    # Step 4: 多路并行召回
    semantic_results = self._search_semantic(enhanced_query)         # 向量/语义
    episode_results = self._search_episodes(enhanced_query)           # 情节关联
    recent_results = self._search_recent(days=3, query=enhanced_query)  # 近3天
    attachment_results = self._search_attachments(query, keywords, intent)  # 附件

    # Step 5: 合并去重
    candidates = self._merge_and_deduplicate(semantic, episode, recent, attachment)

    # Step 6: 综合重排序
    ranked = self._rerank(candidates, query, persona)

    # Step 7: Token 预算内格式化
    return self._format_within_budget(ranked, max_tokens)
```

```python
def should_skip_retrieval(cls, query, recent_messages) -> tuple[bool, str]:
    text = (query or "").strip()
    
    # 跳过条件1：空查询
    if not text:
        return True, "empty"
    
    # 跳过条件2：纯控制词（"好"、"继续"、"嗯"等）
    if lowered in cls._CONTROL_ONLY:
        return True, "control_only"
    
    # 跳过条件3：≤3字符且无上下文的纯短词
    if len(text) <= 3 and not any(h in text for h in cls._KEEP_SHORT_HINTS):

    if len(text) <= 12 and not recent_messages and not any(h in lowered for h in cls._KEEP_SHORT_HINTS):
```

```python
def _compute_recency(dt):
    days = (now - dt).total_seconds() / 86400
    return exp(-0.1 * days)   # 1天≈0.90, 3天≈0.74, 7天≈0.50, 30天≈0.05
```

**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">焦点增强</font>**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">：如果 </font>`<font style="color:rgb(96, 96, 96);background-color:rgb(236, 236, 236);">RetrievalEngine</font>`<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);"> 设置了 </font>`<font style="color:rgb(96, 96, 96);background-color:rgb(236, 236, 236);">_focus_terms</font>`<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">（IntentAnalyzer 给出），命中的候选项 score × 1.0~1.35。</font>

**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">动作词惩罚</font>**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">：fact 类型但内容前 30 字符含动作词（"打开"、"安装"、"部署"等），score × 0.3。</font>

**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">冷启动豁免</font>**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">：recency_score ≥ 0.99（≈ 1 小时内）即便综合分 < 0.35 也保留。</font>

**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">最小阈值</font>**<font style="color:rgb(32, 32, 32);background-color:rgb(250, 250, 253);">：低于 0.35 分的记忆不进入 Prompt。</font>

```plain
IntentAnalyzer 分析用户消息
    ↓ 提取 memory_keywords（LLM 拆解关键词）
    
build_system_prompt()  ← 每轮推理前调用
    ↓
MemoryQueryPreprocessor.prepare()
    ├─ 反注入过滤（清除历史 Prompt 片段）
    ├─ 守卫检查（空/控制词/超短 → return ""）
    └─ 清洗 recent_messages
    ↓
RetrievalEngine.retrieve()
    ├─ 关键词拆解
    │    ├─ 有 brain → LLM (compiler model) 拆解
    │    └─ 无 brain → 规则（正则 + 停用词）
    ├─ 构建增强查询（原始 + 关键词 + 近期上下文）
    │
    ├─ 多路并行召回
    │    │
    │    ├─ [1] _search_semantic()
    │    │    │ UnifiedStore.search_semantic_scored()
    │    │    │   ├─ search_backend.search()  → ChromaDB (向量) 或 FTS5 (BM25)
    │    │    │   └─ FTS5 fallback 搜索（始终 union）
    │    │    │       └─ SQLite: bm25() + jieba 中文分词
    │    │    │
    │    ├─ [2] _search_episodes()  → 实体名关联 Episode
    │    ├─ [3] _search_recent()    → 近3天高重要性记忆
    │    └─ [4] _search_attachments() → 媒体词触发附件搜索
    │
    ├─ 合并去重（按 memory_id）
    ├─ 综合重排序（Relevance×0.4 + Recency×0.2 + Importance×0.2 + AccessFreq×0.2）
    │    └─ 冷启动豁免、焦点增强、动作词惩罚
    │
    └─ Token 预算内格式化
         ├─ 噪声过滤（系统后台记忆 + 低置信度）
         └─ 事实去重（主语+谓词去重）
    ↓
"## 相关记忆（自动检索）\n" + 记忆文本
    ↓
注入 System Prompt → LLM 推理
```
