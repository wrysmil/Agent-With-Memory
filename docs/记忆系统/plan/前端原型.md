# Nanobot 三层记忆系统 - WebUI 前端原型

> 状态: 📐 原型（markdown 线框，待评审）
> 前置: [`前端与接口设计.md`](./前端与接口设计.md)（API 契约与本页面数据来源）；`数据库设计.md`
> 说明: 本原型**复用既有 Settings 视觉/组件**（深色主题、`#2997FF` 主色、卡片、开关、弹层、删除确认），不在 WebUI 引入新设计语言。线框为示意，最终以组件实现为准。

---

## 0. 设计基调（沿用既有）

- 主题：深色（与 WebUI 全局一致）；主色 `#2997FF`；卡片 1px 边框、圆角 `rounded-xl`、`bg-card`
- 组件复用：设置左侧 `SettingsPage` 外壳 + `SettingsSidebar` 分区导航；`ToggleButton`（开关）；`DeleteConfirm`（删除确认弹层）；`MarkdownText`（content 渲染，防 XSS）；通用 `Button`（primary/ghost/danger）
- 「记忆」是 Settings 新增分区 `SettingsSectionKey = "memory"`，进入后在内容区内部用 **Tab** 切换三个子视图：`语义记忆` / `情节记忆` / `工作记忆`

## 2. 语义记忆（主要维护对象）— 列表 + 搜索 + 增删改

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 语义记忆                                   [ 搜索记忆...⌕   ]  [ + 新建记忆 ] │
│ ──────────────────────────────────────────────────────────────────────── │
│ [类型▾ 「全部」] [优先级▾ 「全部」] [排序▾ 「最近更新」]  结果 24 条         │
│ ──────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ ┌ AutoLayout 卡片列表（每张卡片一记忆，点击展开/进详情）──────────────┐ │
│ │                                                                    │ │
│ │  ⚑ 用户偏好 Python 编程语言                            长期 · 0.85 │ │
│ │  type=PREFERENCE  tags=[编程, Python]                   更新 09-08 │ │
│ │  “写好 SPO：subject=用户  predicate=偏好”                              │ │
│ │  [查看] [编辑] [删除]                                               │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ ┌ ────────────────────────────────────────────────────────────────── ┐  │
│ │  ⚑ uv 配置一次:先 irm 再 add  (经验)                    长期 · 0.72   │  │
│ │  type=EXPERIENCE  tags=[uv, win11]                 [查看][编辑][删除]   │  │
│ └──────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│                            [< 上一页]  页 1/3  [下一页 >]                    │
└────────────────────────────────────────────────────────────────────────────┘
```

**交互**：
- 搜索框：防抖 ~300ms → `GET .../memories/search?q=`；清空回退为列表 `GET .../memories`。
- 筛选：`type / priority` 下拉 + `order=created|importance` 排序，组合刷新列表。
- 空态：无结果时显示"暂无记忆,点击右上角新建"。
- status：`scode/index` 等只读字段标为灰小字；`superseded_by` 存在时卡片角标 "已取代"。

## 3. 新建 / 编辑记忆 对话框

```
┌────────────────────────── 新建记忆 ──────────────────────────┐
│                                                              │
│  内容*  [  multiline textarea（必填）                    ]   │
│         [ 用户偏好采用 PIP/uv 管理依赖                       ]   │
│                                                              │
│  类型    [preference ▾]    优先级  [长长期 ▾]   重要度  [0.85]│
│  标签    [ Python ] [ uv ]  [ + 添加标签 ]                     │
│  SPO    主语[用户]  谓词[偏好]   (可选，用于去重/检索)          │
│  Scope   [global ▾]                                          │
│                                                              │
│  ───────────────────────────────────────────────            │
│  [ 取消 ]                          [ 保存 ]                   │
└──────────────────────────────────────────────────────────────┘
```

- 保存：新建 → `memory.create`；编辑 → `memory.update`。
- 校验：内容非空；类型/优先级为枚举下拉；重要度 `0-1` 滑条。
- 只读字段不在表单内（id / created_at / workspace_id 不可改）。

## 4. 事件记忆（episodes）— 查看 + 删除

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 事件记忆                                    [搜索剧情摘要...  ]              │
│ [会话过滤: [全部 ▾]]     结果: 40 条 (按时间倒序)                              │
│ ──────────────────────────────────────────────────────────────────────── │
│  ▷ 2026-09-08 10:30 · 在 Windows 11 上配置 uv 依赖        completed · 0.7    │
│    主题多: 用户目标;涉及: tests/test_x.py, uv             tools: run_command │
│    [展开详情] [删除]                                                         │
│  ▷ 2026-09-08 09:00 · 为报告加上导出功能                失败 · 0.4            │
│    [展开详情] [删除]                                         │
│                                                                             │
│ ┌── 展开详情面板（抽屉/Dialog）──────────────────────────────┐             │
│ │  goal     用户让 Agent 用 uv 管理依赖                       │             │
│ │  outcome  success  entities  tests/…, uv   tools  read_file…    │             │
│ │  工具调用链                                                  │             │
│ │   ├ 1  run_command  powershell -c "irm"   ✅ 1234ms          │             │
│ │   └ 2  read_file    pyproject.toml        ✅ 12ms            │             │
│ │  关联记忆: 2 条 → 点击跳转语义记忆并定位                     │             │

│ └─────────────────────────────────────────────────────────────┘             │
└────────────────────────────────────────────────────────────────────────────┘
```

- 读取：`GET /api/settings/memory/episodes`（可按 `session_id` 过滤）；详情复用同接口单条 `GET .../episodes/{id}`。
- 删除：`episode.delete` + `DeleteConfirm`。
- 展开：展示 `summary/goal/outcome/entities/tools_used` + 工具调用链（`action_nodes` 折叠表格）;`linked_memory_ids` 可点击跳转记忆子视图。

## 5. 工作记忆（scratchpad）— 编辑 + 自动保存

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 工作记忆                                  [自动保存中…]  [保存]        │
│ ┌────────────────────────────────────────────────────────────┐            │
│ │  内容 (Markdown, 编辑器 + 预览)                            │            │
│ │  ## 当前项目                                                │            │
│ │  - 折叠记忆 WebUI                                            │            │
│ │  ## 近期进展                                          ┌─┐   │            │
│ │  - [07-08 10:30] 完成提取链路    ── 分栏实时预览 ──│预先│   │            │
│ │  ## 未解决的问题                     (MarkdownText)    │     │            │
│ │  - 迁移 completion 枚举            └─┘   │            │
│ │  ## 下一步                        │            │
│ │  - 验证 uv run pytest                │            │
│ ├────────────────────────────────────────────────────────────┤            │
│ │  结构化字段（连同 content 一并保存）                          │            │
│ │  当前焦点   [ uv 在 Windows 11 配置 ]                         │            │
│ │  活跃项目   [ uv-memory ] [ 报告导出 ]  [ + ]                  │            │
│ │  未决问题   [ 枚举对齐 ]            [ + ]                  │            │
│ │  下一步     [ 验证 pytest ]            [ + ]                  │            │
│ └────────────────────────────────────────────────────────────┘            │
└────────────────────────────────────────────────────────────────────────────┘
```

- 载入：`GET /scratchpad`（无记录则初始化空模板）。
- 保存：字段变更防抖输入 → `scratchpad.save`（UPSERT;右上角状态态：未保存 / 保存中… / 已保存）。
- 编辑器用现有 Markdown 编辑/预览控件，渲染走 `MarkdownText`（HTML 已清理）。

## 6. 交互与前端封装落点

| 能力            | 封装                                        | 后端契约（见设计文档 §3）              |
| --------------- | ------------------------------------------- | ---------------------------------------- |
| 语义列表/搜索   | `listMemories` / `searchMemories`           | `GET /api/settings/memory/memories[/search]` |
| 单条 / 统计      | `fetchMemory` / `fetchMemoryStats`          | `GET .../memories/{id}` / `.../stats`       |
| 新建 / 编辑     | `createMemory` / `updateMemory`             | `memory.create` / `memory.update`        |
| 删除            | `deleteMemory`                              | `memory.delete`                          |
| 情节列表/详情   | `listEpisodes` / `fetchEpisode`             | `GET .../episodes` / `.../episodes/{id}`    |
| 情节删除        | `deleteEpisode`                             | `episode.delete`                         |
| 工作记忆读/写   | `fetchScratchpad` / `saveScratchpad`        | `GET .../scratchpad` / `scratchpad.save`    |

- 组件目录建议：`webui/src/components/memc/memorrow/`（`MemoryListView.tsx` / `MemoryEditDialog.tsx` / `EpisodeListView.tsx` / `EpisodeDetailPanel.tsx` / `ScratchpadEditor.tsx`），在 `Settings` 分区下注册 `SettingsSectionKey "memory"`。
- 状态：列表本地 `useState` + 自置 `api 封装`；删除用 `DeleteConfirm`；富文本只用 `MarkdownText`，禁止 `dangerouslySetInnerHTML` 掉入 content（防 XSS）。

## 7. 空态与边界

| 场景                                    | 展示                                      |
| --------------------------------------- | ----------------------------------------- |
| 记忆库为空                              | 居中插画 + "点击右上角新建第一条记忆"     |
| 搜索无结果                            | "无匹配记忆" + 清除筛选按钮               |
| 单条 memory 被 `superseded` | 卡片角标"已取代(由新版本覆盖)"             |
| episode.action_nodes 为空        | 展开面板工具链区显示"无工具调用"            |
| scratchpad 未初始化                | 空 Markdown 模板                        |
