

### 1. 核心关系：记忆生命周期
```plain
┌──────────────────┐      1:N       ┌──────────────────┐      N:1       ┌─────────────────────┐
│  conversations   │◀─────────────│    episodes      │──────────────▶│     memories        │
│   对话记录表       │  session_id  │    情节记忆表      │  source_ep   │     语义记忆表        │
└────────┬─────────┘               └────────┬─────────┘               └──────────┬──────────┘
         │                                  │                                 │
         │ 1:N                             │ 1:N                              │
         │ (待提取)                         │ (关联记忆)                        │
         ▼                                  │                                 │
┌──────────────────┐                       │                                 │
│ extraction_queue │                       │                                 │
│    提取队列表      │                       │                                 │
└──────────────────┘                       │                                 │
                                         ┌──┴─────────────────────────────────┐
                                         │       attachments                  │
                                         │         附件表                     │
                                         └───────────────────────────────────┘
```

**关系说明：**

+ `conversation_turns.session_id → episodes.session_id`：一个会话包含多个情节
+ `episodes.source_episode_id → memories.id`：情节可包含多条语义记忆
+ `memories.source_episode_id → episodes.id`：记忆追溯来源情节
+ `conversation_turns.extracted`：标记对话是否已提取为记忆

## 概述
OpenAkita 记忆系统将记忆分为两大类：

1. **常规记忆**：语义记忆、情节记忆、工作记忆、对话记录、附件、上下文快照等
2. **知识图谱记忆**：MDRM 关系图谱相关的节点、边、实体等（详见 `MDRM知识图谱数据表详解.md`）

本文档专注于**常规记忆**的所有数据表。

## 1. 语义记忆表 - `memories`
存储用户偏好、事实、规则、经验等语义记忆。

| 字段 | 类型 | 默认值 | 说明 | 作用 |
| --- | --- | --- | --- | --- |
| `id` | TEXT | - | 主键，记忆唯一标识 | 全局唯一标识一条记忆，用于被其他表关联引用（如episodes.linked_memory_ids、attachments.linked_memory_ids） |
| `content` | TEXT | - | 记忆内容 | 记忆的核心文本内容，LLM可阅读的事实/偏好/规则描述 |
| `type` | TEXT | 'fact' | 记忆类型 | 区分记忆种类，fact(一般事实)、preference(用户偏好)、skill(技能知识)、error(错误教训)、rule(规则约定)、experience(可复用经验) |
| `priority` | TEXT | 'short_term' | 优先级 | 控制记忆保留周期，short_term(会话后可能清理)/long_term(永久保留) |
| `source` | TEXT | '' | 来源标记 | 记录记忆从哪里来：manual(手动add_memory)、extraction(会话提取)、consolidation(整合生成) |
| `importance_score` | REAL | 0.5 | 重要性评分 | 0-1分数，检索时影响排序权重，分数越高越优先返回 |
| `access_count` | INTEGER | 0 | 访问次数 | 记录被search_memory/检索引用的次数，用于热度计算和权重调整 |
| `tags` | TEXT | '[]' | 标签数组JSON | JSON格式的标签列表，如["工作","编程"]，支持按标签过滤检索 |
| `created_at` | TEXT | - | 创建时间 | 记忆创建时间戳，用于时间范围检索和过期判断 |
| `updated_at` | TEXT | - | 更新时间 | 记忆最后修改时间 |
| `expires_at` | TEXT | NULL | 过期时间 | 设置过期时间点，到期后自动不返回（用于短期临时记忆） |
| `metadata` | TEXT | '{}' | 元数据JSON | 存储额外信息：来源URL、关联项目、原始上下文等 |
| `subject` | TEXT | '' | 主语 | SPO三元组主语，用于知识图谱构建，如"用户"、"项目A" |
| `predicate` | TEXT | '' | 谓词 | SPO三元组谓词，表示关系类型，如"喜欢"、"使用"、"开发" |
| `confidence` | REAL | 0.5 | 置信度 | 记忆的可信度，0-1，低于阈值可能被标记为待确认 |
| `decay_rate` | REAL | 0.1 | 衰减率 | 随时间重要性衰减的速度，值越大衰减越快 |
| `last_accessed_at` | TEXT | NULL | 最后访问时间 | 追踪最近一次被检索的时间，用于热度排序 |
| `superseded_by` | TEXT | NULL | 🔑外键→memories.id | 当该记忆被更新版本替代时，记录新记忆的ID，避免信息重复 |
| `source_episode_id` | TEXT | NULL | 🔑外键→episodes.id | 记忆从哪个情节/任务提取生成，用于追溯记忆来源和上下文 |
| `scope` | TEXT | 'global' | 作用范围 | 控制记忆可见性，global(所有会话可见)/session(仅当前会话)/user(当前用户)/pending_consolidation(待整合)/legacy_quarantine(隔离区) |
| `scope_owner` | TEXT | '' | 拥有者 | scope的具体拥有者标识，如用户ID或会话ID |
| `agent_id` | TEXT | '' | Agent标识 | 区分不同AI Agent产生的记忆，避免跨Agent污染 |
| `user_id` | TEXT | 'default' | 用户ID | 多用户隔离，查询时只返回当前用户的记忆 |
| `workspace_id` | TEXT | 'default' | 工作区ID | 多工作区隔离，支持用户在不同项目间切换 |

## 2. 情节记忆表 - `episodes`
存储会话中完成的任务/情节摘要。

| 字段 | 类型 | 默认值 | 说明 | 作用 |
| --- | --- | --- | --- | --- |
| `id` | TEXT | - | 主键，情节唯一标识 | 全局唯一标识一个情节，用于被memories.source_episode_id关联 |
| `session_id` | TEXT | - | 🔑外键→session_tenants.session_id | 关联到所属会话，可通过session找到所有情节 |
| `summary` | TEXT | - | 情节摘要 | LLM生成的简短摘要，用于list_recent_tasks展示任务内容 |
| `goal` | TEXT | '' | 任务目标 | 用户最初提出的任务/请求描述 |
| `outcome` | TEXT | 'completed' | 结果状态 | 标记任务完成情况，completed(成功完成)/failed(失败)/partial(部分完成) |
| `started_at` | TEXT | - | 开始时间 | 任务开始时间，用于时间排序和历史查询 |
| `ended_at` | TEXT | - | 结束时间 | 任务结束时间 |
| `action_nodes` | TEXT | '[]' | 操作节点JSON | 记录具体操作步骤及结果，如读取文件、调用工具、生成报告等 |
| `entities` | TEXT | '[]' | 实体列表JSON | 任务涉及的对象/文件/项目名称，如["数据.xlsx","报告.pdf"] |
| `tools_used` | TEXT | '[]' | 使用的工具JSON | 任务中用到的工具名称列表，如["read_file","python"] |
| `linked_memory_ids` | TEXT | '[]' | 关联记忆ID | 从该情节提取的语义记忆ID列表，可追溯哪些知识被提取 |
| `tags` | TEXT | '[]' | 标签数组 | 情节分类标签，如["数据分析","周报"] |
| `importance_score` | REAL | 0.5 | 重要性评分 | 0-1分数，检索时影响排序，重要任务权重更高 |
| `access_count` | INTEGER | 0 | 访问次数 | 被list_recent_tasks查询的次数 |

## 与知识图谱记忆的关系
常规记忆与 MDRM 知识图谱记忆（详见 `MDRM知识图谱数据表详解.md`）有以下关联点：

| 关联点 | 说明 |
| --- | --- |
| `memories.subject` / `memories.predicate` | 语义记忆的 SPO 三元组字段为知识图谱提供数据源 |
| `memories.metadata` | 可存储图谱节点 ID，反向追溯 |
| 共享 `session_id` / `user_id` / `workspace_id` | 两种记忆使用相同的多租户隔离机制 |
